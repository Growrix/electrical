# Case Studies Page

## Page Goal
Show proof of complex project delivery and encourage high-value inquiries.

## User Intent
See real project outcomes similar to their needs.

## Primary CTA
- Request Similar Solution

## Secondary CTA
- Explore Service Category

## Section Order
1. Case study hero.
2. Filter controls (service type, property type, city).
3. Case study grid.
4. Highlighted featured project.
5. CTA strip.

## Content Blocks
- Card fields: challenge, solution summary, outcome metric, duration.

## Dynamic States
- Loading: grid skeleton.
- Empty: no match guidance and filter reset.
- Error: fallback list and contact CTA.

## SEO
- Link each card to detail page with descriptive slugs.

## Mobile Rules
- One-column list with compact outcome chips.
