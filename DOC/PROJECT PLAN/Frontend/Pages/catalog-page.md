# Catalog Page

## Page Goal
Show informational equipment/material options and route users to service consultation.

## User Intent
Explore possible product/material options without direct purchase.

## Primary CTA
- Request Installation Quote

## Secondary CTA
- Ask Expert on WhatsApp

## Section Order
1. Catalog intro hero with non-commerce disclosure.
2. Category filters and sort controls.
3. Product/material cards.
4. Guidance section (how to choose).
5. CTA strip for consultation.

## Dynamic States
- Loading: card skeleton.
- Empty: no results with filter reset.
- Error: fallback contact panel.

## SEO
- Indexable informational taxonomy pages.

## Mobile Rules
- Sort/filter in bottom sheet.
