# Services Page

## Page Goal
Help users browse service categories and move to detail pages or direct quote submission.

## User Intent
Find the exact service needed and assess provider credibility.

## Primary CTA
- Request Quote for Selected Service

## Secondary CTA
- Talk to Technician

## Section Order
1. Service index hero.
2. Category filter chips.
3. Service card grid with quick facts.
4. Emergency service banner.
5. Comparison table (when to choose each service).
6. Testimonial row mapped to categories.
7. FAQ for service selection.
8. Sticky CTA rail.

## Content Blocks
- Per service card: title, short problem statement, pricing guidance range, response window, trust badge.
- Category taxonomy from CMS.

## Dynamic States
- Loading: cards and filters skeleton.
- Empty: "No services found" with clear filter reset.
- Error: fallback list and call-to-contact banner.

## SEO
- Indexable category links and internal links to service detail pages.

## Mobile Rules
- Filters collapse into horizontal chips.
- Service cards become stacked with one CTA each.
