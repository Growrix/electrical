# Not Found (404) Page

## Page Goal
Recover from broken or outdated links and route users back into conversion flows.

## User Intent
Find the correct destination quickly.

## Primary CTA
- Go to Home

## Secondary CTA
- Contact Support

## Section Order
1. Friendly error headline.
2. Suggested popular links (services, contact, blog).
3. Quick contact actions.
4. Search input.

## States
- Default only; no dynamic loading required.

## SEO
- Noindex recommended.
